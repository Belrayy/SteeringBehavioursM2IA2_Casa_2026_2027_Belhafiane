## Description

Ecosystem-Evolved est une simulation de vie en temps réel composée de trois types d'êtres vivants : les moutons, les loups et les plantes.

Chaque type d'individu évolue en fonction de son environnement et des pressions exercées par les autres organismes. Au fil du temps, les plantes peuvent devenir vénéneuses, les moutons deviennent plus rapides pour échapper aux loups et plus résistants aux poisons, tandis que les loups développent leur intelligence et leur vitesse pour améliorer leurs capacités de chasse.
